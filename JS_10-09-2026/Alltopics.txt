9. Event Bubbling

Event moves from the target element → parent → ancestor elements.

Basic syntax:

element.addEventListener("event", handler);

Stop bubbling:

event.stopPropagation();

10. Event Capturing

Event moves from the ancestor → parent → target element.

Basic syntax:

element.addEventListener("event", handler, true);

Or:

element.addEventListener("event", handler, {
    capture: true
});

11. Event Delegation

Event delegation uses a parent element to handle events from its child elements.

Basic syntax:

parent.addEventListener("event", (event) => {
    if (event.target.matches("selector")) {
        // code
    }
});

Useful properties:

event.target;
event.currentTarget;

12. Throttling

Throttling limits a function so it runs at most once within a specified time interval.

Basic syntax:

function throttle(callback, delay) {
    let lastTime = 0;

    return function (...args) {
        const currentTime = Date.now();

        if (currentTime - lastTime >= delay) {
            lastTime = currentTime;
            callback.apply(this, args);
        }
    };
}

Usage syntax:

element.addEventListener("event", throttle(callback, delay));

13. Debouncing

Debouncing makes a function execute only after the event stops for a specified time.

Basic syntax:

function debounce(callback, delay) {
    let timer;

    return function (...args) {
        clearTimeout(timer);

        timer = setTimeout(() => {
            callback.apply(this, args);
        }, delay);
    };
}

Usage syntax:

element.addEventListener("event", debounce(callback, delay));

Remove all data

Get number of stored items

Get key by index
