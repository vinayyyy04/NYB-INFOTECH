Advanced Browser Routing

Advanced Browser Routing is a feature of React Router that helps manage navigation in large React applications.
 It provides techniques such as nested routes, dynamic URLs, protected pages,
  and error handling to create a smooth user experience without reloading the browser.

1. Nested Routing

Nested Routing is the process of creating routes inside another route.
 It allows a parent page to display different child pages while keeping the same layout.
  This is useful when multiple related pages share common components such as a navigation bar or sidebar.

Example: A Dashboard page containing Profile, Settings, and Reports pages.

2. Dynamic Routing

Dynamic Routing allows the URL to change based on dynamic values such as IDs or names. 
Instead of creating separate routes for every item, 
a single route can handle multiple pages by using variable values in the URL.

Example: A shopping website where every product has a unique URL like /product/101 or /product/205.

3. Route Parameters

Route Parameters are dynamic values passed through the URL.
 They help identify specific resources, such as a product, user, or student.
React Router provides the useParams() hook to access these values inside a component.

Example: In the URL /student/25, the value 25 is the route parameter representing the student ID.

4. Navigation

Navigation is the process of moving from one page to another within a React application without refreshing the browser.
 React Router provides components and hooks such as Link, NavLink, and useNavigate() to perform navigation efficiently.

Link: Used to navigate between pages.
NavLink: Similar to Link, but highlights the currently active page.
useNavigate(): Used to navigate programmatically after actions like login or form submission.

Example: Clicking the "About" link opens the About page without reloading the application.

5. Protected Routes

Protected Routes restrict access to certain pages based on user authentication or authorization. 
If a user is not logged in or does not have permission, they are redirected to another page, usually the login page.

Example: Pages like Dashboard, Profile, Orders, and Checkout can only be accessed after logging in.

6. 404 (Not Found) Page

A 404 (Not Found) page is displayed when a user tries to access a route that does not exist in the application.
 It informs the user that the requested page cannot be found and usually provides a link to return to the home page.

Example: If a user enters /xyz123 and no such route exists,
 the application displays a custom 404 page instead of a blank screen.
