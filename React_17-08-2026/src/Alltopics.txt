1. Controlled Components

A controlled component is a form element whose value is controlled by React state using useState.

Example: Input value is stored and updated through React state.

2. Uncontrolled Components

An uncontrolled component stores its form value inside the DOM, and React accesses it using a ref.

Example: Using useRef() to read an input value when the form is submitted.

3. Form Handling

Form handling means collecting user input, managing form state, handling submission, 
and processing the entered data.

Example: Handling a login form with username and password fields.

4. Form Validation

Form validation checks whether the entered data is correct and meets required conditions before submitting.

Example: Checking that an email is valid and a password is at least 8 characters.

5. Dynamic Form Fields

Dynamic form fields are form inputs that can be added, removed, or changed based on user actions.

Example: An employee form where users can click “Add Skill” to create additional skill fields.
