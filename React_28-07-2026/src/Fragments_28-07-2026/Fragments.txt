A Fragment in React is a special feature that allows you to group multiple JSX elements together
 without adding an extra HTML element (such as a <div>) to the webpage.

In React, every component must return a single parent element. 
If you need to return multiple elements, you would normally wrap them inside a <div>. 
However, adding unnecessary <div> elements can make the HTML structure 
more complex and may sometimes affect the layout or CSS.

Fragments solve this problem by acting as an invisible wrapper. 
They let you return multiple elements while keeping the Document Object Model (DOM) 
clean because they do not create any extra HTML elements.

Why are Fragments used?
To group multiple JSX elements under a single parent.
To avoid adding unnecessary <div> elements to the DOM.
To keep the HTML structure clean and simple.
To prevent layout issues that extra wrapper elements might cause.
To improve code readability and maintainability.

When to Use React Fragments:-

When you only need to group multiple JSX elements.
When you want to avoid unnecessary HTML elements.
When keeping the DOM clean is important.
When working with tables, lists, or layouts where extra wrapper elements are not needed.
When to Use Normal HTML Wrapper Elements
When you need to apply CSS styles.
When you need to attach event handlers.
When you need a container for layout using Flexbox or Grid.
When the wrapper itself has semantic meaning (such as <section>, <article>, or <main>).
