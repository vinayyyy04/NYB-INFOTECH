React Router

React Router is a library used in React to navigate between 
different pages or components without refreshing the entire webpage.

BrowserRouter

BrowserRouter is the main container that enables routing in a
React application and keeps the UI synchronized with the browser URL.

Routes and Route

Routes contains all the routes in the application, 
while Route connects a specific URL path to the component that should be displayed.

Dynamic Routing

Dynamic Routing allows a route to contain changing values, 
such as a product ID or employee ID, so the same component can display
 different data based on the URL.

Example: /products/101 and /products/102.

Protected Routes

Protected Routes restrict access to certain pages and allow only 
authenticated or authorized users to access them, such as a dashboard after login.
