1. Object Destructuring

Used to extract values from an object into variables.

const user = { name: "Sowmith", age: 22 };

const { name, age } = user;
2. Object Methods

Functions stored inside an object.

const user = {
  name: "Sowmith",
  greet() {
    console.log("Hello");
  }
};

user.greet();
3. Object.keys()

Returns an array of all keys in an object.

const user = { name: "Sowmith", age: 22 };

console.log(Object.keys(user));
// ["name", "age"]
4. Object.values()

Returns an array of all values in an object.

console.log(Object.values(user));
// ["Sowmith", 22]
5. Object.entries()

Returns an array containing key-value pairs.

console.log(Object.entries(user));
// [["name", "Sowmith"], ["age", 22]]
6. Object.assign()

Used to copy or merge objects.

const obj1 = { name: "Sowmith" };
const obj2 = { age: 22 };

const result = Object.assign({}, obj1, obj2);
7. Optional Chaining (?.)

Safely accesses a property that might not exist.

const user = {};

console.log(user.address?.city);

Returns undefined instead of causing an error.

8. Nullish Coalescing (??)

Provides a default value when the value is null or undefined.

const name = null;

console.log(name ?? "Guest");
// "Guest"
9. Spread Operator (...)

Expands or copies values from an object or array.

const user = { name: "Sowmith" };

const updatedUser = {
  ...user,
  age: 22
};
10. Rest Operator (...)

Collects remaining values into an array or object.

const { name, ...details } = {
  name: "Sowmith",
  age: 22,
  city: "Hyderabad"
};

console.log(details);
